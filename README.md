Offizielle Download-Seite für **AIR Launcher** – einen schlanken, D-Pad-optimierten Launcher für Android TV.

## Installation

> **Wichtig:** Die Installation muss über die **Google Play Store App** erfolgen. Installationen über APK/ADB werden nicht unterstützt.

Die veröffentlichten Dateien in den [Releases](https://github.com/barezi5527/AIR-Launcher-Downloads/releases) dienen als offizielle Release-Ablage.

## Highlights

- **9 Designs:** Klassisch, Kino, Neon, Mono, Air-G, Air-L, Air-S+, Air-A, Air-S.
- **TV-Steuerung:** Vollständig per D-Pad/OK bedienbar, inkl. Verschiebemodus.
- **Anpassbar:** Akzentfarbe, Hintergrund, Schriftfarbe, Kachelgröße, Spalten, App-Namen, Animationen.
- **Favoriten & Ordnung:** Eigene Favoriten, App-Reihenfolge und App-Sichtbarkeit.
- **Lesbarkeit:** Gute Kontraste und automatische Hintergrund-Aufhellung bei dunkler Schrift.
